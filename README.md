# Salman Umer — Portfolio

Personal portfolio site for **Salman Umer**, Tech Recruiter & Business Development Specialist based in Lahore, Pakistan.

Connecting companies with top software engineering talent, and guiding developers toward the right opportunities. A recruiter who understands code (React.js, Next.js, React Native, Firebase).

## Tech

A single, self-contained `index.html` — no build step, no dependencies. Fonts (Fraunces + Inter) load from Google Fonts. Just open the file or serve the folder.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Adding a photo

The hero shows an `SU` monogram by default. To use a real headshot, drop a `headshot.jpg` in this folder and, in `index.html`, replace the monogram line inside `.portrait .frame`:

```html
<span class="mono-lg">SU</span>
```

with:

```html
<img class="photo" src="headshot.jpg" alt="Salman Umer"/>
```
